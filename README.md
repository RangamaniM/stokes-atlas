# Stokes atlas accompanying geodesicsWKB

Interactive Stokes graphs accompanying geodesicsWKB. Explore the
general-momentum and core regimes of planar and global Schwarzschild–AdS
black holes and planar Reissner–Nordström–AdS5. Coordinates, frequency
conventions and turning-point labels follow the manuscript. Parameters
are stated for each example.

Open index.html in a browser, or browse the GitHub Pages site. The viewers
work offline and need no installation. Drag a sphere or use the arrow keys
to rotate it; select roots or crossings to highlight their trajectories.

- General momentum: 45 graphs, five backgrounds, three momenta and phases.
- Resolved core: ten neutral graphs and three RNAdS5 graphs.
- Print atlases: general-momentum and neutral-core collections.
- Notation: coordinates, frequency phase, turning-point and horizon labels.

Please cite geodesicsWKB by Hewei Frederic Jia and Mukund Rangamani.
